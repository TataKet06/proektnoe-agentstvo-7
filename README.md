# Проектное агентство · 7 класс

Готовый мобильный квест: 8 миссий, 24 задания и паспорт учебного проекта.
Все необходимые файлы находятся в этом архиве. Сборка и платные сервисы не нужны.
Квест не подключается к ChatGPT, CDN, внешним шрифтам или аналитике.

## Публикация на GitHub Pages

1. Войдите в свой аккаунт на https://github.com/ и создайте публичный репозиторий
   с названием proektnoe-agentstvo-7. Для бесплатного Pages нужен публичный репозиторий.
2. Распакуйте архив. Загрузите все файлы из него в корень ветки main.
   Файл index.html должен лежать прямо в корне, а не во вложенной папке.
   Сохраните .nojekyll, если ваша система скрывает файлы с точкой в начале имени.
3. Откройте Settings → Pages → Build and deployment.
   Выберите Deploy from a branch, затем main и /(root). Нажмите Save.
4. Дождитесь успешной публикации. На странице Pages появится точный адрес сайта.
   Он имеет вид https://ВАШ-ЛОГИН.github.io/proektnoe-agentstvo-7/.
   Это пример формата, а не готовая ссылка на опубликованный квест.
5. Откройте полученный адрес на телефоне без VPN через школьный Wi-Fi и мобильный
   интернет. После проверки сделайте QR-код на этот адрес.

Ученикам для открытия опубликованного квеста не нужно входить в GitHub или ChatGPT.
Официальная инструкция: https://docs.github.com/en/pages/quickstart
Условия бесплатного Pages:
https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages

## Другой хостинг

Эти же файлы можно загрузить на любой хостинг HTML/CSS/JavaScript с HTTPS.
Для GitVerse Pages: создайте публичный репозиторий, включите CI/CD, загрузите файлы
в корень main, затем откройте Настройки → Страницы и включите публикацию из ветки.
Инструкция: https://gitverse.ru/docs/pages/quick-start/

## Работа с классом

Прогресс и ответы сохраняются в текущем браузере текущего устройства.
На новом адресе сайта начинается новое прохождение: браузерные данные между
доменами автоматически не переносятся.
Ученик может скачать паспорт, скопировать текст или распечатать его.
Серверного журнала класса и автоматической отправки работ учителю нет.
Раздел «Учителю» с ключом доступен всем посетителям; квест рассчитан на обучение.
Содержание открытых ответов оценивает учитель, приложение проверяет заполнение.
Примеры школьной статистики в заданиях — тренировочные данные.

При замене файлов на хостинге сохраняйте их имена и расположение.
Открывайте приложение по HTTPS; запуск index.html двойным щелчком из папки
может блокировать JavaScript-модули в браузере.
